# Commerce Brain

Commerce Brain to prywatna, wewnętrzna aplikacja sklepu **Exclusive Kicks**.
Nie jest udostępniana innym sprzedawcom, sprzedawana ani dystrybuowana.

## Cel aplikacji

Aplikacja korzysta z **Allegro REST API** wyłącznie na potrzeby konta
sprzedawcy Exclusive Kicks, aby analizować:

- **sprzedaż** — zamówienia i ich rozliczenia,
- **stany magazynowe** — zgodność stanów ofert ze wspólnym stanem magazynu,
- **rentowność** — przychody, opłaty i koszty na poziomie zamówienia i produktu,
- **kampanie** — udział ofert w kampaniach i ich wpływ na wynik sprzedaży.

Wyniki służą właścicielowi sklepu do podejmowania decyzji biznesowych.

## English summary

Commerce Brain is a private, internal application of the **Exclusive Kicks**
store. It is not offered, sold or distributed to other sellers. It uses the
**Allegro REST API** only for the Exclusive Kicks seller account, to analyse
sales, stock levels, profitability and campaigns. This repository contains
only this description; the application's source code is private.
